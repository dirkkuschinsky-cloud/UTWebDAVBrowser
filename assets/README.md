# App icon provenance

## Origin

On 2026-10-22, the project owner confirmed that the original PNG reference,
`Cloud-Speicher-App-Symbol mit Ordner und Pfeilen.png`, was generated with
ChatGPT (OpenAI) for the UT WebDAV Browser project. The current `logo.svg` was
subsequently created on the basis of that reference.

The design was not taken from a known external icon library. This provenance
statement records the project owner's account; it is not an independent
clearance of all possible third-party rights.

The SVG contains vector paths, rectangles, gradients and a clipping path. It
contains no embedded raster images or externally linked resources. Its `url()`
references point only to definitions within the same SVG file.
